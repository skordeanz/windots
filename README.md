## 🌷 About

**windots** is a collection of dotfiles and configs for a riced, Unix-like Windows 11 setup — tiling window management, a Catppuccin color scheme, and thoughtful UI tweaks for productivity and aesthetics.

> [!NOTE]
> **Installation guide:** see [install.md](install.md) for setup steps.

## ✨ Features

- 🪟 **GlazeWM** tiling window manager
- ❄️ **YASB** status bar
- 🚀 **Flow Launcher** with Catppuccin theme
- >_ **Windows Terminal** custom styling
- 🐚 **PowerShell** profile with **Oh My Posh** prompt
- 🌸 **VSCode** + **Zed** Catppuccin setups
- 🎵 **Spicetify**, 💬 **Vencord**, 🎬 **mpv** configs
- 🦅 **Windhawk** Start menu / Taskbar / Notification styling
- 🎯 **Nile Soft Shell** right-click menu
- 🖱️ **File Explorer** cursors, theme, and blur
- 🐈 [**Catppuccin**](https://catppuccin.com) everywhere
- 💫 Beautiful [**Wallpapers**](wallpapers/)

## 🔗 Directory Structure

```
windots/
├── configs/
│   ├── autohotkey/      # Volume & mute scripts
│   ├── browser/         # Zen Browser userChrome/userContent + bookmarks
│   ├── explorer/        # Cursors, themes, blur effects
│   ├── fastfetch/       # System fetch configs
│   ├── flowlauncher/    # Launcher configs & Catppuccin theme
│   ├── glazewm/         # Tiling window manager
│   ├── mpvplayer/       # Video player configs
│   ├── nilesoft/        # Shell menu customization
│   ├── ohmyposh/        # Prompt theme
│   ├── powershell/      # PowerShell profile
│   ├── qbittorrent/     # Torrent client theme
│   ├── raycast/         # Launcher config
│   ├── spicetify/       # Spotify customization
│   ├── stylus/          # Browser extension styles
│   ├── terminal/        # Windows Terminal settings
│   ├── thunderbird/     # Email client chrome theme
│   ├── vencord/         # Discord theme settings
│   ├── vscode/          # VS Code settings
│   ├── windhawk/        # Windows UI mods
│   ├── yasb/            # Status bar config
│   └── zed/             # Zed editor configs
├── wallpapers/          # Wallpapers
└── install.md           # Installation guide
```
